# **App Name**: YoriGames

## Core Features:

- Celestial Title Screen: A high-impact landing area featuring a massive pixel-art animated title and space-themed visual elements that respond to interaction.
- Cartridge Strip Explorer: Netflix-style horizontal rows for game browsing, where each card resembles a collectible arcade cartridge with hover-glow and elevation effects.
- Arcade Insight Tool: A search tool powered by AI that identifies games from descriptive queries like 'nighttime cosmic runner' to suggest highly relevant gameplay experiences.
- Neon Command Console: An intuitive navigation navbar utilizing pixel-accurate borders, neon purple glow pulses, and game-menu-inspired transitions.
- Cosmic Layout Manager: A floating panel interface designed for the homepage layout, organizing Trending and Recently Added games in clear categories.
- Spacefield Parallax Engine: A background system utilizing framer-motion to create subtle, drifting pixel-art clouds, shooting stars, and pulsing planets for atmospheric depth.
- AI Genre Scout: A recommendation tool that analyzes play history to generate dynamic genre-based labels and quirky, pixel-flavored game tags.

## Style Guidelines:

- The visual palette is anchored in a Cosmic Neon scheme with a deep navy-purple background (#09061B), a vibrant Purple primary (#A855F7) for branding, and a striking Neon Pink accent (#EC4899) for interactive elements and CTAs.
- Primary branding and headers utilize 'Pixelify Sans' or 'Press Start 2P' for authentic retro vibes, while body text and long descriptions use 'Inter' for readability. Note: currently only Google Fonts are supported.
- Handcrafted pixel-art icons used for category tags, navigation markers, and action buttons to maintain game-world immersion.
- A 'Game Launcher' structure combining large-scale cinematic hero banners with structured, Netflix-inspired categorization strips.
- Framer Motion animations for slow-drifting cosmic objects and sharp pixel-transition hover states for an authentic indie-game tactile feel.
