# YoriGames

A modern web-based arcade platform for premium indie pixel-art games. Play instantly in your browser without any downloads.

## Author
**Yogesh Yadav**

## Tech Stack
- **Framework:** Next.js (App Router)
- **Database & Auth:** Firebase (Firestore, Auth, Storage)
- **Styling:** Tailwind CSS
- **UI Components:** ShadCN UI & Lucide Icons
- **AI Integration:** Genkit for game discovery

## Getting Started

### Installation
Clone the repository and install dependencies:

```bash
npm install
```

### Development
Run the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build
To create a production build:

```bash
npm run build
```

## Project Structure
- `src/app`: Application routes and layouts
- `src/components`: Reusable UI and pixel-art components
- `src/firebase`: Firebase configuration and custom hooks
- `src/lib`: Utility functions and data access layer
- `src/ai`: Genkit flows for personalized recommendations
